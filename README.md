# Find Every Child

Campaign site for **Find Every Child**, Project Q2's response to the 2026 measles outbreak in Bangladesh.

The whole site is one self-contained file, `index.html` (photos, map data and sound are embedded), so it can be hosted anywhere, including GitHub Pages.

## What's on the page

- Poster hero with an opt-in story: a dramatized WhatsApp-style chat (fictional family, events drawn from reporting in The Daily Star), followed by "what Project Q2 is doing" with music
- Outbreak curve and a division-level heat map of Bangladesh (DGHS figures)
- Fundraising progress, plan, stages, FAQ

## Before launch

Highlighted placeholders still need real details: field partner, advisors, target settlements, donate link, HCB ledger link, and the policy for funds if the $50,000 trigger isn't reached. The Lovelo display font is not included yet (Bebas Neue is the stand-in).
